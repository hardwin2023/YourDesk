# 本地離線更新

「設定 → 關於 → 本地更新」使用已下載的 YourDesk 套件更新這台電腦，不查詢 GitHub、不下載額外的服務套件。

1. Windows 選擇符合目前程式架構的完整 Portable ZIP；macOS 選擇 DMG。不必先解壓縮或掛載，可重新命名套件檔名。Service ZIP、一般檔案 ZIP 及其他平台的套件不適用。
2. 程式先建立私有暫存副本，驗證內容、架構及版本資訊。ZIP 同時核對完整 `SHA256SUMS`；DMG 以唯讀方式掛載，核對 APP 識別與簽章。驗證不執行套件內程式，也不替換現有安裝。
3. 畫面顯示「目前版本 → 所選版本」。本地更新不比較版本高低，允許升版、同版本修復及回退，不受「強制更新」開關限制。版本資訊仍須符合 YourDesk 的封裝格式。
4. 按「開始更新」才進行安裝，沒有自動倒數。程式準備好獨立更新程序後才結束，遠端連線會中斷；替換完成後自動重新開啟。

驗證途中或確認前，可按「取消」、右上角關閉或 Esc，清除本次暫存；結束 APP 也會取消尚未交接的工作。來源 DMG／ZIP 不被修改。準備失敗時保留目前程式；交接後若替換、服務檢查或開啟新版失敗，更新程序嘗試還原並重新開啟舊版，保留錯誤記錄供檢查。

## 已安裝系統服務

本地更新同步替換 APP 與既有服務副本，保留服務配對設定、登入前啟動模式及 Ctrl+Alt+Del 狀態。不需先移除服務，也不會因本地更新自動開啟登入前啟動。

Windows 本地套件需要替換受保護服務時，正常更新由 Windows 要求一次 UAC 授權；取消不結束 APP、不替換檔案。更新以原帳號重新開啟 APP；不支援在另一個帳號下提供 UAC 憑證。若服務已更新、但新 APP 無法開啟，原有的服務還原流程會再次要求管理員授權。系統服務檔案會與已驗證的 APP 副本核對雜湊，且須連續三次收到舊版亦支援的 `status` 管線回覆才完成。回退前清除 `updater.protocol` 與 `desktop-control.v1` 等協定標記，支援對應協定的服務會自行重建；失敗則連同原檔案一起還原標記。

離線更新不把使用者指定的路徑或雜湊交給已授權 SYSTEM 更新器。既有線上 OTA 仍由受保護服務自行下載官方 Service ZIP，沿用原本的免重複 UAC 流程。兩者的信任來源及授權流程不同。

macOS 若已安裝登入前服務，依原有更新機制要求管理員授權，更新 APP 與受保護的服務副本，並檢查 broker／代理交接；一般模式直接更新目前安裝位置。安裝目錄仍須可寫入。

已發布的舊版若沒有「本地更新」按鈕，仍須先手動安裝含此功能的版本。Windows 舊版要手動替換 ZIP 時，請先在進階設定「移除系統服務」，避免 APP 與服務副本版本不同。回退到不具備本地更新的版本後，下一次更新須依該舊版提供的方式操作。不同版本的設定相容性依套件本身決定，本地更新不轉換舊版設定格式。

## 驗證範圍

- Go／race Smoke：版本升降與同版修復、確認前不安裝、OTA 互斥、內容變更拒絕、錯誤不退出、取消與過期 ID、私有暫存清理、API 驗證，以及真實 HTTP 未送完檔案時的取消。
- 瀏覽器 Smoke：真正的 HTML／JS，Windows ZIP／macOS DMG、四語窄視窗、取消／Esc、驗證失敗、重新整理後繼續及一次確認交接；使用隔離 API，確認無對外下載。
- macOS 原生 Smoke：原生選檔視窗、實際唯讀掛載 DMG、可回退版本、錯誤識別／架構／版本及簽章破壞，皆使用微型隔離套件。
- 更新腳本 Smoke：隔離執行真正的 macOS shell 與 Windows PowerShell 流程，測試 APP／服務更新、保留設定及各階段失敗回復。Windows 使用真實 .NET 本機管線，SCM／UAC 以替身測試，不操作真實服務。

這些測試不代表已完成 Windows 實機 UAC／SCM 或更新後 P2P 重連驗收。
